Política de privacidade

Como a {{ barbearia.nome }} usa os seus dados, conforme a Lei Geral de Proteção de Dados (Lei nº 13.709/2018).

Quem cuida dos seus dados

A {{ barbearia.nome }}, localizada em {{ barbearia.endereco }}, é a responsável pelos dados coletados neste site. Para qualquer dúvida ou pedido sobre os seus dados, fale conosco pelo telefone {{ barbearia.telefone }} ou pelo WhatsApp.

Com quem compartilhamos

Não vendemos nem compartilhamos seus dados com outras empresas para fins de propaganda. Os dados ficam guardados no serviço de hospedagem do site, que só os armazena para que o sistema funcione.

Por quanto tempo guardamos

Mantemos o histórico de agendamentos enquanto você for cliente, para facilitar novos agendamentos. Você pode pedir a exclusão a qualquer momento.

Seus direitos

Pela LGPD (art. 18), você pode pedir para:

  • saber quais dados seus nós temos;
  • corrigir dados incompletos ou errados;
  • excluir os seus dados;
  • retirar o consentimento dado para cookies opcionais.

É só falar conosco pelos contatos acima.
